Comprehensive Rules lookup

mtg-rules

A free way to find a rule in the official Magic: The Gathering Comprehensive Rules. Type a rule number or a few words. What comes back is the official wording, in the same structure the document uses.

  • Rule numbers are the address. 704.5f always means that rule, in this document and in the next one.
  • The text is shown as written. Examples travel with the rule. This page does not judge card interactions.
  • Reading it is free. The rules data is not sold or paywalled. The code that parses it is MIT.
