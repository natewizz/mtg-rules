Use the rules text in an app

The search pages are for a person reading a rule. An app should download the versioned release, then read a rule by its id. The text is the official wording. It does not judge a card interaction.

Pin the release

Start from the pointer on main. It names the data tag, the effective date, and the file URLs. Save rulesUrl with your build. Read this pointer again when you want a newer edition. 

https://raw.githubusercontent.com/natewizz/mtg-rules/main/latest.json

The current pointer is v0.2.0-data.2, effective September 25, 2026. Do not pin rules.json from this website. That copy changes when the site is deployed and is not the contract.

Refuse the wrong file

Before you show any wording, require all of these:

  • profile is complete-generated-document.
  • unofficial is true.
  • freeUseOnly is true.

Also fetch noticeUrl and keep that notice with the data. The rules text is free to use only, and it may not be sold or paywalled. MIT covers the parser code. It does not cover the Wizards-owned text. 

const latest = await fetch(
  'https://raw.githubusercontent.com/natewizz/mtg-rules/main/latest.json',
).then((response) => response.json());

if (
  latest.profile !== 'complete-generated-document' ||
  latest.unofficial !== true ||
  latest.freeUseOnly !== true
) {
  throw new Error('This pointer is not the free, unofficial rules release.');
}

const rules = await fetch(latest.rulesUrl).then((response) => response.json());
const rule = rules.rules['704.5f'];

Read a rule

rules.rules['704.5f'] is the rule. Each entry has id, text, and examples. Glossary entries live on rules.glossary, keyed by the term, such as Trample. Chapter titles live on rules.sections.

A keyword heading such as 702.19 is only the name Trample. The definition continues in 702.19a, 702.19b, and the rest of that lettered run. 702.190 is a different keyword.

Tournament rules

The Magic Tournament Rules are a second document. The same pre-release publishes mtr.json beside rules.json. Take the rulesUrl and change the filename to mtr.json. latest.json does not name that file yet, so do not wait for a field that is not there.

Require metadata.dataProfile to be complete-generated-tournament-rules, with the same unofficial and free-use notices. Look up rules['2.12'] or rules['Appendix C']. Each entry has id, title, section, and text.

Browser agents

An agent that can open this site in a browser with document.modelContext can call lookup-rule, search-rules, lookup-glossary, lookup-tournament-rule, and search-tournament-rules. Those tools answer one lookup. They are not a replacement for pinning rulesUrl in an app.
