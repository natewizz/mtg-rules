# Security

`mtg-rules` is pre-1.0 software. Please avoid including official Comprehensive Rules TXT files, generated full-rules JSON, credentials, or other sensitive material in issues and pull requests.

For security issues involving the code, open a private GitHub security advisory if that feature is enabled for the repository. Otherwise, contact the repository maintainer privately through GitHub before opening a public issue.

Do not use public issues for private Wizards licensing correspondence. Generated rules JSON, when distributed, must remain free to use and must include the unofficial notices in `NOTICE.md`.
